My Toronto setup is built for long compile sessions and quiet focus.

Hardware goals:

- enough cores for local builds without melting the room
- NVMe storage for large asset projects
- dual-purpose gear that works for both school and client demos

Tooling goals:

- Docker for reproducible services
- Redis for caching and queues when apps need it
- Git hygiene so freelance and studio work never collide

The best setup is the one that disappears while you work.
